# مبدل — https://mobadel.github.io

مبدل ارز دیجیتال، طلا، سکه و ارز به تومان. یک صفحهٔ کاملاً استاتیک روی GitHub Pages، بدون سرور و بدون هزینه.

## ساختار

```
index.html                        صفحهٔ اصلی
assets/assets.js                  رجیستری دارایی‌ها (مرورگر + Node)
assets/app.js                     منطق تبدیل، جستجو، جابه‌جایی
assets/styles.css                 طراحی (RTL، پوستهٔ روشن/تاریک)
data/prices.json                  آخرین قیمت‌ها — با Actions به‌روز می‌شود
data/brs-catalog.json             فهرست خام رکوردهای BrsApi (برای نگه‌داری)
scripts/fetch-prices.mjs          دریافت قیمت از سه منبع
.github/workflows/update-prices.yml   زمان‌بندی هر ۱۰ دقیقه
```

## منابع قیمت و دلیل معماری

| منبع | endpoint | چه چیزی | از کجا کار می‌کند |
|---|---|---|---|
| **نوبیتکس** | `api.nobitex.ir/market/stats` | قیمت تومانی رمزارزها | **فقط مرورگر** |
| **Binance** | `data-api.binance.vision` | قیمت دلاری رمزارزها | **فقط Actions** |
| **BrsApi** | `api.brsapi.ir/Market/Gold_Currency.php` | طلا، سکه، ارز، نرخ تتر | **فقط Actions** |

این تقسیم‌بندی حدس نیست؛ هر سطرش با اجرای واقعی روی runner آزموده شده:

1. **BrsApi کلید می‌خواهد.** از مرورگر یعنی لو رفتن کلید در سورس صفحه و سوختن سهمیهٔ رایگان با هر بازدید. پس کلید در GitHub Secrets می‌ماند.
2. **`api.binance.com` به runnerهای گیت‌هاب `HTTP 451` می‌دهد** (بلاک جغرافیایی آی‌پی آمریکا). میزبان `data-api.binance.vision` همان دادهٔ عمومی بازار را بدون این محدودیت می‌دهد.
3. **نوبیتکس از runnerهای گیت‌هاب اصلاً resolve نمی‌شود** (`fetch failed`، روی هر دو میزبان `api` و `apiv2`). پس قیمت تومانی رمزارز فقط از مرورگرِ کاربر داخل ایران می‌آید.

### زنجیرهٔ اولویت قیمت رمزارز

```
نوبیتکس (تومان، مرورگر)  →  USDT_IRT از BrsApi  →  قیمت دلاری بایننس × لنگر تتر
```

لنگر تبدیل دلار به تومان به ترتیب: تترِ نوبیتکس، بعد `USDT_IRT`، بعد نرخ دلار. تتر بر دلار مقدم است چون رمزارز در ایران با تتر معامله می‌شود.

**نکتهٔ مهم:** لنگر هرگز از دادهٔ `seed` یا `stale` برداشته نمی‌شود. اگر این را رعایت نکنید، قیمت دلاری واقعی در یک عدد ساختگی ضرب می‌شود و نتیجه با اطمینان کاذب «تازه» علامت می‌خورد — این باگ یک‌بار واقعاً رخ داد.

بنابراین Actions هر ۱۰ دقیقه هر سه را می‌خواند و در `data/prices.json` می‌ریزد؛ مرورگر همان فایل را می‌خواند و **علاوه بر آن** نوبیتکس را زنده امتحان می‌کند تا قیمت رمزارز تازه‌تر باشد. اگر هر کدام شکست بخورد، دیگری جواب می‌دهد.

اگر منبعی از کار بیفتد، مقدار قبلیِ همان دارایی حفظ می‌شود (`kept` در فایل JSON) تا صفحه هرگز خالی نشود. ولی `stale` علامت می‌خورد، صفحه هشدار می‌دهد و اجرای ورک‌فلو قرمز می‌شود — دادهٔ قدیمی هرگز به‌جای تازه جا نمی‌زند.

## مسیرهای مجاز تبدیل

**تومان ↔ هر دارایی. و تمام.** همیشه یک سمتِ تبدیل تومان است؛ تبدیل دارایی به دارایی (بیت‌کوین به تتر، یورو به دلار) وجود ندارد.

منطقش در `counterpartsOf()` داخل `assets/assets.js` متمرکز است و در سه جا اعمال می‌شود: فهرست انتخابگر، چیپ‌های میان‌بر، و اعتبارسنجی لینک `#from-to`. اگر جای دیگری اضافه کردید، حتماً از همین تابع استفاده کنید.

در انتخابگر، خودِ دارایی سمت مقابل هم در فهرست می‌ماند و انتخابش مسیر را برعکس می‌کند. به همین دلیل وقتی مقصد تومان است، تومان در فهرست مبدأ دیده می‌شود و انتخابش تبدیل را به «تومان به آن دارایی» برمی‌گرداند.

## نقره پشتیبانی نمی‌شود

`api.brsapi.ir/Market/Gold_Currency.php` هیچ رکورد نقره‌ای ندارد — جستجو روی هر ۵۶ رکورد با نام (نقره، سیم) و نماد (SILVER، XAG، SLV) صفر نتیجه داد. به همین دلیل از فهرست دارایی‌ها حذف شد.

اگر روزی منبعی برایش پیدا شد، یک ورودی به `assets/assets.js` اضافه کنید. **قیمت ساختگی نگذارید** — یک‌بار همین کار باعث شد صفحه عدد جعلی را به‌عنوان قیمت واقعی نشان دهد.

## `data/brs-catalog.json`

هر اجرای موفق، فهرست خام `symbol` و `name` و `unit` همهٔ رکوردهای BrsApi را اینجا می‌نویسد. وقتی دارایی‌ای در `missing` ظاهر شد، نام درستش را از این فایل بردارید و به فیلد `brs` اضافه کنید — لازم نیست حدس بزنید. این فایل فقط وقتی بازنویسی می‌شود که BrsApi جواب داده باشد.

## راه‌اندازی

### ۱. ساخت ریپو
با اکانت `mobadel` یک ریپوی **عمومی** به نام دقیق `mobadel.github.io` بسازید (بدون README یا .gitignore).

### ۲. آپلود کد

```bash
cd mobadel
git remote add origin https://github.com/mobadel/mobadel.github.io.git
git push -u origin main
```

### ۳. گرفتن کلید BrsApi
از [brsapi.ir](https://brsapi.ir/) ثبت‌نام کنید و کلید رایگان بگیرید. سپس در ریپو:

`Settings → Secrets and variables → Actions → New repository secret`

- Name: `BRSAPI_KEY`
- Secret: کلید شما

> بدون این کلید، بخش طلا/سکه/ارز قیمت نخواهد داشت و فقط رمزارزها کار می‌کنند.

### ۴. فعال‌سازی Pages
`Settings → Pages → Source: Deploy from a branch → Branch: main / (root)`

چند دقیقه بعد صفحه روی `https://mobadel.github.io` بالا می‌آید.

### ۵. اولین اجرای قیمت‌ها
`Actions → به‌روزرسانی قیمت‌ها → Run workflow`

در لاگ، خطوط `منابع:` نشان می‌دهد کدام منبع جواب داده است.

## نکات نگه‌داری

- **زمان‌بندی تضمینی نیست.** GitHub در ساعات شلوغ ممکن است اجرای cron را چند دقیقه عقب بیندازد یا رد کند. برای همین مرورگر هم مستقیم نوبیتکس را می‌خواند.
- **ورک‌فلوهای زمان‌بندی‌شده پس از ۶۰ روز بی‌فعالیتی در ریپو غیرفعال می‌شوند.** گیت‌هاب ایمیل می‌دهد؛ با یک کامیت یا کلیک روی Enable دوباره فعال می‌شود.
- **نام‌های BrsApi ممکن است فرق کند.** در `assets/assets.js` هر دارایی فیلد `brs` دارد که فهرستی از نامزدهاست و اولین تطابق برنده می‌شود. اگر داراییی در `missing` ظاهر شد، نام درست را از `data/brs-catalog.json` بردارید.
- **فیلتر `paths` را به تریگر `push` برنگردانید.** هنگام ساخته‌شدن شاخهٔ جدید، گیت‌هاب مسیرها را با کامیت قبلی می‌سنجد که وجود ندارد و ورک‌فلو اصلاً اجرا نمی‌شود.
- **افزودن دارایی جدید** فقط یک ورودی در `assets/assets.js` می‌خواهد؛ بقیهٔ صفحه خودکار ساخته می‌شود.

## اجرای محلی

```bash
node scripts/fetch-prices.mjs        # نیازمند BRSAPI_KEY در محیط
python -m http.server 8000           # سپس http://localhost:8000
```

فایل‌ها با `fetch` بارگذاری می‌شوند، پس باز کردن مستقیم `index.html` با `file://` کار نمی‌کند.

## سلب مسئولیت

این صفحه ابزار محاسبه است، نه مرجع معامله. قیمت‌ها از منابع عمومی شخص ثالث می‌آیند و ممکن است با تأخیر یا خطا همراه باشند.
