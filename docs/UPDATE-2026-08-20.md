# سند تغییرات — ۲۰ اوت ۲۰۲۶

این سند برای تحویل به یک هوش مصنوعی یا توسعه‌دهندهٔ دیگر نوشته شده. هدفش این است که بدون دسترسی به تاریخچهٔ گفتگو، بشود فهمید چه چیزی عوض شد و **چرا**.

پروژه: **تبدکس** — مبدل قیمت، فارسی، RTL، بدون فریم‌ورک (وانیلا جاوااسکریپت، سبک ES5).

### نکتهٔ حیاتی دربارهٔ دیپلوی

`lftp` با `mirror --reverse` و **بدون `--delete`** اجرا می‌شود. یعنی:

- فایل جدید یا تغییریافته آپلود می‌شود ✅
- فایلی که از ریپو حذف شود، **روی سرور باقی می‌ماند** ❌

پس حذف فایل از سرور باید دستی از cPanel انجام شود.

## ۲. منابع داده

دو منبع کاملاً مستقل. **عمداً هیچ دارایی از هر دو منبع قیمت نمی‌گیرد** — دو نرخ متفاوت برای یک دارایی یعنی گراف تبدیل ناسازگار می‌شود.

### الف) نوبیتکس — سمت مرورگر

- ارز دیجیتال + تومان
- مستقیم از مرورگر کاربر: `https://apiv2.nobitex.ir/market/stats` و `/v2/options`
- بدون کلید، بدون پراکسی

> ⚠️ `api.nobitex.ir` **در DNS وجود ندارد** (تست شد: `DNS name does not exist`). فقط `apiv2.nobitex.ir` جواب می‌دهد. در `assets/app.js` آرایهٔ `hosts` قبلاً `api` را اول داشت و هر بار یک درخواست محکوم‌به‌شکست می‌ساخت؛ ترتیب برعکس شد. نام مرده به‌عنوان فالبک نگه داشته شد چون در مسیر موفق هیچ هزینه‌ای ندارد.

### ب) BrsApi — سمت سرور، از راه پراکسی

- طلا، سکه، ارز فیات
- `https://api.brsapi.ir/Market/Gold_Currency.php?key=...`
- سهمیهٔ رایگان: **۱۵۰۰ درخواست در روز**
- پاسخ سه آرایه دارد: `gold`، `currency`، `cryptocurrency`

**چرا پراکسی و نه صدا زدن مستقیم از مرورگر؟**

1. کلید در جاوااسکریپت عمومی دیده می‌شد
2. با ۱۵۰۰ درخواست در روز، سهمیه با ترافیک بسیار کم ته می‌کشید

با کش ۱۲۰ ثانیه‌ای، مصرف **حدود ۷۲۰ درخواست در روز** است — مستقل از تعداد بازدیدکننده. (تأیید شد: سه فراخوانی در ۰٫۸ ثانیه، هر سه از یک کش.)

### `api/rates.php` — پراکسی نرخ

- کش: `api/cache/rates.json` با TTL **۱۲۰ ثانیه**
- نوشتن کش **اتمیک** است (فایل موقت + `rename`) تا درخواست هم‌زمان، فایل نیمه‌نوشته نخواند
- خروجی **قرارداد خودمان** است نه شکل خام BrsApi، تا اگر روزی منبع عوض شد فقط همین فایل تغییر کند
- در هر خطا (کلید نبود، بالادست خطا داد، JSON خراب بود) آخرین کش سالم با فلگ `stale: true` برگردانده می‌شود تا صفحه هرگز خالی نشود
- اگر واحد بالادست «ریال» باشد بر ۱۰ تقسیم می‌شود (دفاعی؛ فعلاً تومان می‌دهد)

شکل خروجی:

```json
{
  "updated": "2026-08-20T16:14:01+00:00",
  "fetched_unix": 1787255241,
  "stale": false,
  "assets": {
    "gold18": {
      "toman": 19852700,
      "group": "gold",
      "unit": "gram",
      "name": "طلای 18 عیار",
      "change": 0.47
    }
  }
}
```

### کلید BrsApi — کجاست؟

- **هرگز در ریپو نیست.** در `.gitignore` هم مسدود شده
- در GitHub به‌صورت سکرت `BRSAPI_KEY` ذخیره است
- ورک‌فلو هنگام دیپلوی آن را داخل `_site/api/config.php` می‌نویسد
- چرا فایل PHP و نه فایل متنی؟ چون فایل PHP **اجرا** می‌شود و محتوایش سرو نمی‌شود؛ یک فایل `.txt` کلید را لو می‌داد
- برای فرار از مشکلات نقل‌قول در شل، کلید base64 می‌شود و در PHP دیکد
- اگر سکرت نباشد، ورک‌فلو **عمداً نمی‌شکند**؛ فقط `::warning::` می‌دهد و بقیهٔ سایت منتشر می‌شود

## ۴. قانون تبدیل — مهم‌ترین بخش منطق

دو مفهوم **جدا** هستند و نباید قاطی شوند:

- **لایهٔ نرخ** (`findRate`): آیا مسیر محاسباتی وجود دارد؟
- **لایهٔ سیاست** (`isPairAllowed`): آیا این تبدیل **مجاز** است؟

بدون این جداسازی، طلا از راه تومان به بیت‌کوین وصل می‌شد — چون مسیر ریاضی وجود دارد.

### دسته‌ها

```js
MESH_GROUPS = { crypto, fiat }   // شبکهٔ کاملاً به‌هم‌پیوسته
LEAF_GROUPS = { gold, coin }     // برگ — فقط به تومان
```

**تومان (`irt`) در دستهٔ `fiat` است، نه یک دستهٔ جدا.** این عمدی است و روی تگ‌های رابط کاربری هم اثر دارد.

### ماتریس

| از ↓ / به ← | ارز دیجیتال | تومان | ارز فیات | طلا | سکه |
|---|:---:|:---:|:---:|:---:|:---:|
| **ارز دیجیتال** | ✅ | ✅ | ✅ | ❌ | ❌ |
| **تومان** | ✅ | — | ✅ | ✅ | ✅ |
| **ارز فیات** | ✅ | ✅ | ✅ | ❌ | ❌ |
| **طلا** | ❌ | ✅ | ❌ | — | ❌ |
| **سکه** | ❌ | ✅ | ❌ | ❌ | — |

منطق در `isPairAllowed(from, to)`:

```js
if (LEAF[from] && LEAF[to]) return false;   // طلا ↔ سکه ممنوع
if (LEAF[from]) return to === "irt";        // طلا فقط با تومان
if (LEAF[to])   return from === "irt";
return MESH[from] && MESH[to];              // بقیه آزاد
```

`findRate` در همان ابتدا این را صدا می‌زند و اگر مجاز نبود `null` برمی‌گرداند. `availableCurrencies(counterpartId)` هم فهرست انتخاب را فیلتر می‌کند تا کاربر **اصلاً نتواند** جفت نامعتبر بسازد. اگر جابه‌جایی طرفین جفت نامعتبر بسازد، `selectCurrency` طرف مقابل را به تومان برمی‌گرداند.

## ۵. تغییرات رابط کاربری

دیزاین عمداً دست‌نخورده ماند. فقط این‌ها اضافه شد:

**۱) تگ دستهٔ دارایی زیر فیلد جستجو** — `همه` · `ارز دیجیتال` · `طلا و سکه` · `ارز`

- «طلا و سکه» یک تگ است هرچند در کد دو دستهٔ جداست، چون کاربر آن‌ها را یک خانواده می‌بیند
- تگ و متن جستجو با هم **AND** می‌شوند
- استایل از توکن‌های موجود می‌آید: `--green`، `--green-soft`، `--border`، همان حلقهٔ فوکوس فیلد جستجو

**۲) برچسب واحد** — «۱ **گرم** طلای ۱۸ عیار = …». بدون این، عددی که کاربر وارد می‌کند مبهم است. در فهرست دارایی هم برای طلا و سکه به‌جای نام انگلیسی، «هر گرم» و «هر عدد» نشان داده می‌شود.

**۳) نوار وضعیت منبع‌آگاه** — زمانِ همان منبعی را نشان می‌دهد که جفت فعلی از آن آمده. برای تبدیل‌هایی که از هر دو منبع عبور می‌کنند (مثل دلار ← بیت‌کوین)، **قدیمی‌ترین** زمان و بدبینانه‌ترین حالت «زنده بودن» نمایش داده می‌شود.

### آیکون‌ها

- **پرچم‌ها**: نسخهٔ **مربعی `1x1`** از [flag-icons](https://flagicons.lipis.dev/) با لایسنس MIT، هم‌خانوادهٔ `ir.svg` که از قبل بود. مربعی لازم است چون `.currency-icon` با `border-radius: 50%` و `overflow: hidden` و `object-fit: cover` گرد برش می‌زند
- **`gold-18k.svg`**: وکتور تمیز ۹۰۸ بایتی، full-bleed، برش گرد تمیز می‌شود
- **`coin-emami.png`**: **از ۱۶۹ KB به ۲۷ KB رسید.** فایل اصلی وکتور نبود؛ دو PNG بود پیچیده در SVG (یکی تصویر ۳۰۸×۳۰۸ و یکی ماسک دایره‌ای) که ۹۹٪ حجم فایل را می‌ساختند. ماسک به‌عنوان کانال آلفا روی تصویر سوار و در ۱۲۸ پیکسل بازفشرده شد. توجه: تصویر خام پس‌زمینهٔ **سیاه** دارد، پس بدون اعمال ماسک حلقهٔ سیاه دور سکه می‌افتد

## ۶. باگی که رفع شد

`buildMarketGraph` با `state.graph = {}` کل گراف را از نو می‌سازد. نوبیتکس معمولاً **دیرتر** از پراکسی جواب می‌دهد، پس طلا و ارز فیات درست بعد از رسیدن پاسخ نوبیتکس از فهرست ناپدید می‌شدند.

**راه‌حل:** آخرین payload پراکسی در `state.proxyAssets` نگه داشته می‌شود و `applyProxyEdges()` بعد از هر بازسازی گراف دوباره صدا زده می‌شود.

## ۷. افزودن دارایی جدید — فقط دو ردیف

مثلاً پوند، طلای ۲۴ عیار، یا ربع سکه:

**۱) در `api/rates.php` داخل `ASSET_MAP`:**

```php
'GBP' => ['id' => 'gbp', 'group' => 'fiat', 'unit' => 'unit'],
```

نماد را از پاسخ خام BrsApi بردارید.

**۲) در `assets/app.js` داخل جدول دارایی‌های پراکسی:**

```js
{ id: "gbp", code: "GBP", name: "پوند", englishName: "British Pound",
  decimals: 2, group: "fiat", unit: null, localIcon: "assets/flags/gb.svg" },
```

`group` تعیین می‌کند دارایی به چه چیزهایی تبدیل شود. هیچ جای دیگری نیاز به تغییر نیست. اگر آیکون لازم است از `flags/1x1/` همان مخزن بگیرید.

## ۸. تست‌ها

```bash
node tests/converter.test.js
```

هارنس یک DOM جعلی می‌سازد و `assets/app.js` را با `vm.runInThisContext` اجرا می‌کند. `fetch` استاب شده است. توابع داخل IIFE‌اند و مستقیم در دسترس نیستند، پس همه‌چیز از راه DOM تست می‌شود.

تست‌های اضافه‌شده:

- ماتریس مجاز و غیرمجاز (طلا فقط با تومان؛ یورو نه به طلا و نه به سکه)
- فیلتر شدن فهرست بر اساس دارایی طرف مقابل
- تگ‌های دسته و AND شدنشان با متن جستجو
- تومان زیر تگ «ارز» می‌آید نه «ارز دیجیتال»
- تبدیل یورو ← دلار از راه تومان (اعداد گرد انتخاب شده تا `۱٫۲` دقیق دربیاید)
- برچسب واحد در نمایش نرخ

> نکته: در فهرست مقصد، **خودِ دارایی مبدأ هم دیده می‌شود**. این رفتار از قبل وجود داشت و کلیک روی آن یعنی جابه‌جایی دو طرف. عمداً حفظ شد.

## ۹. کارهای دستی باقی‌مانده

1. **`api/_phpcheck.php` را از cPanel پاک کنید.** فایل پروب موقتی بود؛ محتوایش خالی شد و حالا ۴۰۴ برمی‌گرداند، ولی چون `lftp` بدون `--delete` است از سرور حذف نمی‌شود
2. **سکرت `PARS_FTP_DIRECTORY`** ظاهراً مقدارش `/` است. گیت‌هاب هر `/` را در لاگ ماسک می‌کند، برای همین مسیرها در لاگ به شکل `data***prices.json` دیده می‌شوند. خطر امنیتی ندارد ولی لاگ را ناخوانا می‌کند
3. **`set ssl:verify-certificate no`** در ورک‌فلوی دیپلوی. کامنتش می‌گوید به‌خاطر زنجیرهٔ ناقص گواهی پارس‌پک است، ولی عملاً رمز FTP بدون بررسی گواهی فرستاده می‌شود و در برابر MITM باز است

## ۱۱. جمع‌بندی رفتار فعلی

- **ارز دیجیتال**: همه به همه، به تومان، به تتر — بدون هیچ تغییر نسبت به قبل
- **طلای ۱۸ عیار** (هر گرم) و **سکه امامی** (هر عدد): فقط ↔ تومان
- **دلار، یورو، لیر، درهم**: ↔ تومان، ↔ یکدیگر، ↔ ارز دیجیتال
- منبع طلا و سکه و فیات: BrsApi از راه پراکسی با کش ۱۲۰ ثانیه
- منبع ارز دیجیتال: نوبیتکس، مستقیم از مرورگر
