# داده‌های ساختاریافته (Schema.org / JSON-LD)

> قاعدهٔ اصلی: اسکیما ادعای ماشین‌خوان است. هر نود فقط وقتی منتشر می‌شود
> که محتوای متناظرش واقعاً روی همان صفحه باشد.

سازنده‌ها در `scripts/schema.mjs` (توابع خالص) و تصمیم «کدام صفحه چه نودی»
در `scripts/build-pages.mjs` است. قرارداد را `tests/schema.test.js` روی
همهٔ آدرس‌های سایت‌مپ بررسی می‌کند.

## نقشهٔ صفحه ← نود

همهٔ صفحه‌ها: `Organization` (`/#organization`) و `WebSite` (`/#website`)،
و یک نود صفحه با `@id` برابر `canonical + #webpage`.

| صفحه | نود صفحه | فرزندها | شرط |
|---|---|---|---|
| `/` | `CollectionPage` | `mainEntity` ← `ItemList` شش کارت بالای صفحه، `hasPart` ← مبدل | |
| `/convert/` | `WebPage` | `mainEntity` ← `WebApplication` مبدل | |
| `/convert/rahn-ejare/` | `WebPage` | `mainEntity` ← `WebApplication` ماشین حساب رهن و اجاره، با شناسهٔ مستقل و بدون `Offer` | |
| `/convert/x-to-y/` و صفحه‌های `?amount=` | `WebPage` | `about` ← دو `Thing`، `hasPart` ← مبدل | |
| `/price/` | `CollectionPage` | `ItemList` دسته‌ها، `BreadcrumbList` | |
| `/price/<دسته>/` | `CollectionPage` | `ItemList` دارایی‌ها، `BreadcrumbList` | رمزارز `ItemList` ندارد ↓ |
| `/price/<دسته>/<دارایی>/` | `WebPage` | `about` و `mainEntity` ← `Thing`، `BreadcrumbList` | |
| همان، با نمودار | | `hasPart` ← `Dataset` | فقط وقتی تاریخ شروع واقعی داده در `data/market-history.json` هست |
| `/about/` | `AboutPage` | `about` ← سازمان | |
| `/contact/` | `ContactPage` | `about` ← سازمان | |
| `/methodology/` | `WebPage` | `publisher` (نه `about`) | |
| `/mag/` | وردپرس (Yoast) جدا می‌سازد | | کارهای پنل ↓ |

`Thing` هر دارایی شناسهٔ `/price/<دسته>/<دارایی>/#thing` دارد و صفحهٔ
قیمت و همهٔ جفت‌های مبدلش به همان اشاره می‌کنند. دارایی بی‌صفحهٔ قیمت
(تومان، گرام) شناسه را زیر `/convert/#<اسلاگ>` می‌گیرد.

صفحه‌های قیمتِ ساخته‌شده `data-built` دارند و `assets/price.js` آن‌ها را
بازنویسی نمی‌کند. فقط آدرس‌هایی که از راه بازنویسی قالب خام را می‌گیرند
(رمزارزهای خارج از سایت‌مپ) اسکیمای سادهٔ سمت مرورگر می‌گیرند — بدون قیمت.

## تصمیم‌های ردشده (۱۴۰۵/۰۸/۱۳ — 2026-11-04)

**بدون `Offer` روی مبدل.** `WebApplication` پیش‌تر `offers: {price: 0, priceCurrency: IRR}`
داشت. هر تایپی که عدد قیمت می‌پذیرد رابطهٔ فروشنده↔خریدار می‌سازد؛
`isAccessibleForFree: true` همان «رایگان» را بدون آن ادعا می‌گوید.
هزینه‌اش: گوگل برای نتیجهٔ ویژهٔ نرم‌افزار `offers` می‌خواهد، پس آن جلوه را نمی‌گیریم.

**بدون قیمت در صفحه‌های دارایی.** `price.js` پیش‌تر `Dataset` با قیمت لحظه‌ای،
تغییر ۲۴ ساعته و `dateModified` لحظه‌ای می‌نوشت و آن را `mainEntity` صفحه
می‌کرد. گوگل عدد را روزها کش می‌کند، پس نتیجهٔ جستجو قیمت کهنه نشان می‌داد.
موضوع صفحه دارایی است (`Thing`)، نه جدول قیمت.

**بدون `Product` / `FinancialProduct` / `ExchangeRateSpecification`.** تبدکس
نمی‌فروشد و ارائه‌دهندهٔ محصول مالی نیست. `ExchangeRateSpecification` مجاز
بود ولی نرخ HTML اولیه نرخِ لحظهٔ دیپلوی است و همان مشکل کش را دارد.

**بدون `Dataset` برای رمزارزها.** نمودارشان از نوبیتکس می‌آید و تاریخ شروع
واقعی داده‌شان اینجا معلوم نیست؛ `2017-01-01` کف درخواست است، نه شروع داده.
طلای ۲۲، ۲۱، ۲۰، ۱۷ و ۱۴ عیار هم سری جدا در `market-history.json` ندارند.

**بدون `license` روی `Dataset`.** داده با مجوز باز منتشر نشده و صفحهٔ شرایط
استفاده هم نداریم.

**بدون `ItemList` در `/price/crypto/`.** فهرست حدود ۲۸۰ رمزارز را جاوااسکریپت
از بازار زنده می‌سازد و ترتیبش عوض می‌شود؛ فهرست ثابتی که با صفحه یکی باشد نیست.

**بدون `SearchAction`.** جستجوی `/price/#search` سمت مرورگر است و صفحهٔ نتایج ندارد.

**بدون `FAQPage`.** پرسش‌های متن شش جفت (`PAIR_CONTENT`) تیتر مقاله‌اند، نه بخش
پرسش متداول؛ گوگل هم از ۲۰۲۳ نتیجهٔ ویژهٔ FAQ را برای اکثر سایت‌ها برداشته.

**`Organization` و نه `FinancialService`.** آن تایپ `LocalBusiness` است و آدرس
و ساعت کاری می‌خواهد؛ تبدکس هیچ‌کدام را ندارد.

**بدون `foundingDate`.** تاریخ دقیق میلادی را نداریم؛ تاریخ شمسی در این فیلد
بی‌صدا «سال ۱۴۰۵ میلادی» خوانده می‌شود.

**بدون `BreadcrumbList` روی صفحه‌های مبدل و صفحهٔ اصلی.** بردکرامب روی خود صفحه نیست.

## تله‌های گرفته‌شده (اندازه‌گیری روی خروجی زنده، 2026-11-04)

- هیچ صفحه‌ای `Organization` نداشت؛ `WebSite` ناشر نداشت.
- ۱۳۰ صفحهٔ قیمت در HTML اولیه یک نود یکسان `{"@type":"WebPage","name":"قیمت لحظه ای دارایی"}`
  بدون `url` داشتند؛ اسکیمای واقعی فقط بعد از اجرای جاوااسکریپت ساخته می‌شد.
- صفحه‌های جفت و `?amount=` اسکیمای `/convert/` را تکرار می‌کردند و نود صفحهٔ خودشان را نداشتند.
- «درباره ما»، «تماس» و «روش محاسبه» هیچ اسکیمایی نداشتند.
- مجله: `Organization` با `@id` جدا (`/mag/#organization`)، یعنی گوگل دو برند می‌بیند،
  و `alternateName` با غلط تایپی «مجله تدبکس».

## کارهای باقی‌مانده

**پنل وردپرس (مجله):**
- Yoast ← Settings ← Site representation: `alternateName` را از «مجله تدبکس» به «Tabdex» اصلاح کن.
- یکی‌کردن `@id` سازمان مجله با `https://tabdex.ir/#organization` به فیلتر
  `wpseo_schema_organization` (یا `wpseo_schema_graph`) در قالب/افزونهٔ کوچک نیاز دارد.

**کد / داده:**
- `sameAs` ویکی‌دیتا روی `Thing` دارایی‌ها، فقط با فهرست دستی و تأییدشده.
- اگر تاریخ شروع واقعی دادهٔ نمودار رمزارزها معلوم شد، `Dataset` آن‌ها.
- لوگوی سازمان فعلاً `apple-touch-icon.png` (۱۸۰ پیکسل) است؛ نسخهٔ ۵۱۲ پیکسلی بهتر است.
