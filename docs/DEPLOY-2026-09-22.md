# سند تحویل دیپلوی — ۲۲ سپتامبر ۲۰۲۶ (۳۱ شهریور ۱۴۰۵)

این سند برای سشنی نوشته شده که روی ویندوز باز می‌شود و تاریخچهٔ گفتگوی
قبلی را ندارد. هدفش این است که بدون هیچ context دیگری بشود کار
نیمه‌تمام را تمام کرد.

پروژه: **تبدکس** — مبدل قیمت، فارسی، RTL، بدون فریم‌ورک.
سایت زنده: `https://tabdex.ir` · هاست: پارس‌پک (FTPS)

---

## خلاصهٔ یک خطی

کد کامل و تست‌شده روی برنچ `main` است، ولی **سه فایل به سرور نرسیده‌اند**
چون دیپلوی خودکار گیت‌هاب از ۲۰ سپتامبر از کار افتاده. نتیجه: دستهٔ
«انرژی» روی سایت خالی است.

---

## ۱. چه کاری باید انجام شود

این فایل‌ها روی `main` هستند ولی روی سرور نیستند:

| فایل | بدون آن چه می‌شکند |
|---|---|
| `api/rates.php` | **مهم‌ترین** — `brent` و `gasoline` اصلاً در خروجی API نیستند |
| `assets/home.js` | ردیف «نفت برنت» در جدول صفحهٔ اول نمی‌آید |
| `index.html` | مرورگر `home.js` کش‌شدهٔ قدیمی را می‌گیرد |
| `sitemap.xml` | (کم‌اهمیت) |

### راه الف — اسکریپت آماده

مخزن `tools/deploy.sh` دارد که همان کار ورک‌فلو را می‌کند. در **Git Bash**
یا **WSL** (نه PowerShell):

```bash
git checkout main && git pull

export FTP_SERVER=...
export FTP_USERNAME=...
export FTP_PASSWORD=...
export FTP_DIRECTORY=...          # ریشهٔ سایت روی هاست، معمولاً /public_html
export BRSAPI_KEY=...             # اختیاری — ندهی، config.php روی سرور دست‌نخورده می‌ماند
export HISTORY_CAPTURE_TOKEN=...  # اختیاری، فقط همراه BRSAPI_KEY

bash tools/deploy.sh --quick
```

- `--quick` فقط ۱۳ فایل (`api/`، `assets/`، HTMLهای دست‌نویس) را می‌فرستد و
  مولد صفحه‌ها را اجرا نمی‌کند. صفحه‌های `/price/energy/` از قبل روی سرور
  هستند، پس همین کافی است.
- بدون گزینه = دیپلوی کامل (۶۰۹ فایل، چند دقیقه).
- `--dry-run` فقط می‌سازد و چیزی آپلود نمی‌کند.
- `lftp` لازم است. در WSL: `sudo apt install lftp`.
- اسکریپت خودش بعد از آپلود تأیید md5 می‌گیرد.

### راه ب — FileZilla (بدون نصب چیزی)

```
git checkout main && git pull
```

بعد این سه فایل را با حفظ مسیر آپلود کن:

```
api/rates.php     →  <ریشهٔ سایت>/api/rates.php
assets/home.js    →  <ریشهٔ سایت>/assets/home.js
index.html        →  <ریشهٔ سایت>/index.html
```

### بعد از هر دو راه

فایل `<ریشهٔ سایت>/api/cache/energy.json` را **پاک کن** (اگر هست). کش قدیمی
است و تا منقضی نشود نرخ تازه ساخته نمی‌شود.

### مقادیر FTP از کجا می‌آیند

از **کاربر بپرس**. در GitHub Secrets مخزن هم هستند:
`PARS_FTP_SERVER`، `PARS_FTP_USERNAME`، `PARS_FTP_PASSWORD`،
`PARS_FTP_DIRECTORY`، `PARS_FTP_PORT`، `BRSAPI_KEY`،
`HISTORY_CAPTURE_TOKEN`. هیچ‌کدام را در فایل یا کامیت ننویس.

## ۲. تأیید نهایی — تا این‌ها را ندیدی تمام‌شده اعلام نکن

۱. اسکریپت باید برای هر فایل `✓` بدهد و آخرش «انتشار کامل».

۲. API باید دو نماد تازه داشته باشد:

```bash
curl -s https://tabdex.ir/api/rates.php \
  | python -c "import json,sys; a=json.load(sys.stdin)['assets']; print('brent:', 'brent' in a); print('gasoline:', 'gasoline' in a)"
```

۳. `https://tabdex.ir/price/energy/` با `Ctrl+Shift+R` — باید «نفت برنت» و
   «بنزین آمریکا» با قیمت تومانی بیایند، نه «دارایی‌ای با این عبارت پیدا نشد».

۴. صفحهٔ اول باید ردیف «نفت برنت» داشته باشد.

### اگر باز هم نیامدند

- `api/cache/energy.json` و `api/cache/rates.json` را روی هاست پاک کن.
- پاسخ خام بالادست را ببین:
  `https://api.brsapi.ir/Market/Commodity.php?key=<BRSAPI_KEY>`
  ردیف‌هایش زیر کلیدهای `metal_precious`، `metal_base` و `energy` هستند.
  تابع `flattenSymbolRows()` در `api/rates.php` باید آن‌ها را مسطح کند —
  اگر ساختار عوض شده باشد، همین تابع جای اصلاح است.

## ۳. چرا دیپلوی خودکار کار نمی‌کند

از **۲۰ سپتامبر ۲۰۲۶، ۱۳:۴۷ UTC** همهٔ ورک‌فلوهای این مخزن در ۲ تا ۹ ثانیه
شکست می‌خورند و **هیچ لاگی تولید نمی‌کنند**:

| ورک‌فلو | وضعیت |
|---|---|
| Deploy to ParsPack | ❌ |
| Checks (php-lint) | ❌ |
| BrsApi probe | ❌ |
| کرون‌های زمان‌بندی‌شده | ❌ |

بررسی‌شده و رد شده:

- ورک‌فلوها `active` هستند، غیرفعال نشده‌اند.
- به `environment: production` ربط ندارد — `php-lint` هم که ندارد شکست می‌خورد.
- اجرای دوباره هم همین‌طور شکست می‌خورد.
- جاب‌ها شروع می‌شوند و فوراً می‌میرند، پیش از آنکه هیچ گامی اجرا شود.

این الگوی **تمام‌شدن دقیقه‌های GitHub Actions یا مسئلهٔ پرداخت** است.
`Settings → Billing and plans` را چک کنید. تا آن درست نشود هر تغییر بعدی
هم دستی می‌خواهد.

## ۴. چه چیزی در این چند روز عوض شد (زمینه)

اگر لازم شد بدانی چرا کد به این شکل است:

### نرخ‌ها و ساعت به‌روزرسانی
- `api/rates.php`: عمر کش ثابت ۳۰۰ ثانیه‌ای جای خود را به `marketTtl()` داد —
  ۶۰ ثانیه در ساعات بازار ایران، ۱۸۰ در حاشیه، ۶۰۰ شب‌ها و جمعه.
- شمارندهٔ سهمیهٔ روزانه در `api/cache/quota.json`: بالای ۱۲۰۰ درخواست،
  TTL خودکار به ۳۰۰ برمی‌گردد. سقف رایگان BrsApi ۱۵۰۰ در روز است.
- `updated` در پاسخ حالا زمان دریافت خودمان است، نه `time_unix` بالادست
  (که می‌توانست دقایقی عقب باشد). `ttl` هم بیرون داده می‌شود تا مرورگر
  هم‌فاز با انقضای کش دوباره بگیرد.
- مرورگر (`app.js`، `home.js`، `price.js`) هر ۶۰ ثانیه تازه می‌کند، فقط
  وقتی تب قابل‌رؤیت است و صفحه ربع ساعت اخیر تعاملی داشته.

### نمودارها
- ثبت نقاط از کرون گیت‌هاب جدا شد و به `api/rates.php` منتقل شد (هر بار که
  کش تازه می‌شود، با سطل پنج‌دقیقه‌ای). دلیل: کرون روی کاغذ هر ۵ دقیقه بود
  ولی GitHub آن را throttle می‌کرد و در عمل هر ۲ تا ۵ ساعت اجرا می‌شد.
- منطق ساعت بازار در `api/market-history.php` مشترک شد.

### دستهٔ انرژی (کار فعلی)
- `BRENT` و `RBOB` از اندپوینت `Commodity` می‌آیند. قیمت دلاری است و مثل
  انس طلا با نرخ دلار به تومان تبدیل می‌شود.
- «بنزین آمریکا» عمداً نام کامل دارد تا با بنزین جایگاه‌های داخلی اشتباه
  نشود.
- ساعت بازار به وقت **نیویورک** حساب می‌شود (یکشنبه ۱۸:۰۰ تا جمعه ۱۷:۰۰،
  با وقفهٔ یک‌ساعتهٔ روزانه)، نه با اختلاف ثابت از تهران — چون آمریکا ساعت
  تابستانی دارد و ایران ندارد.
- TTL: ۶۰۰ ثانیه بازار باز، ۳۶۰۰ بسته. حدود ۱۰۷ درخواست در روز.

### دیپلوی
- `mirror --ignore-time` فقط اندازهٔ فایل را می‌بیند، پس تغییر هم‌اندازه
  بی‌صدا جا می‌ماند. حالا فایل‌های تغییرکردهٔ هر پوش از گیت گرفته و
  بی‌قیدوشرط `put` می‌شوند.
- گام «تأیید انتشار روی سرور» md5 چند فایل کلیدی را با نسخهٔ زنده مقایسه
  می‌کند و اگر یکی نبود دیپلوی را قرمز می‌کند.
- `scripts/` دیگر منتشر نمی‌شود (فایل‌های `.php` آنجا روی سرور اجرا
  می‌شدند و `.py` به‌صورت متن سرو می‌شد). ابزارهای توسعه در `tools/`اند.

## ۵. کارهای باز

- **بیلینگ Actions** — تا درست نشود، دیپلوی خودکار برنمی‌گردد.
- **`IME/Certificate` با HTTP 402 جواب می‌دهد** — اندپوینت گواهی سپردهٔ
  بورس کالا دیگر در پلن رایگان نیست. نقره و مس روی سایت از کش قدیمی
  می‌آیند. جایگزین احتمالی: همان اندپوینت `Commodity` (انس نقره و مس
  جهانی دارد، ولی دلاری است نه ریال بورس کالا — تصمیم محصولی است).
- **پوشهٔ `scripts/` روی سرور** — دیگر به‌روز نمی‌شود ولی نسخهٔ قدیمی‌اش
  هنوز آنجاست. `mirror` بدون `--delete` اجرا می‌شود، پس حذفش دستی است.
- **`sitemap-legacy.xml`** — موقتی است؛ بعد از اینکه گوگل آدرس‌های قدیمی را
  دوباره خزید باید حذف شود.

## ۶. ابزارهای مفید

- `tools/deploy.sh` — دیپلوی مستقل از Actions (بالا توضیح داده شد).
- `tools/brs-probe.php` — می‌گوید با کلید رایگان فعلی چه اندپوینت‌هایی در
  دسترس‌اند، شکل پاسخشان چیست، و خروجی زندهٔ سایت چه داراییی دارد.
  با `BRSAPI_KEY=... php tools/brs-probe.php` اجرا می‌شود.
  ورک‌فلوی دستی `BrsApi probe` هم همین را اجرا می‌کند (وقتی Actions کار کند).
- `node --test tests/*.test.js` — چهار فایل تست، همه باید سبز باشند.
